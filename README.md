# Sizzle Production Planner

Sizzle

Sizzle provides food services for offices, including self-serve fridges stocked with warm and cold lunches and snacks. I manage catering, rotating chefs, web-app integration, office pantry offerings, and customer communication.

I want to create an interactive application that will enable me to register the requirement for each location along with a percentage of that being vegan. the solution should then pick up products from that week as entered in the db and create a production register. Once total production is registered there needs to be another page that handles allotment of these items to each location based on production and requirement. Once that is done a page should show packing information for each location for that day. that is location a gets x, y and z based on allotment. On a given week there should be another page where a personnel can register returns (unsold) from each location for the week before. so we need to pull dish data from previous week. I have backend made in supabase and connecting it will make this all make more sense to you. ask me for supabase project url and key in chat to add as env. i dont want to go through the oauth
